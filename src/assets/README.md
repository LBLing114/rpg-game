# 雾渡美术资源

本目录的四张图集使用生成式美术工具为本项目专门制作，角色设计与场景设定来自《雾渡》。不是 RPG Maker 编辑器自带的 RTP 素材。运行游戏时无需生成服务或 API 密钥。

| 图集 | 内容 | 游戏中的用途 |
| --- | --- | --- |
| `portraits.png` | 沈砚、周姨、林岚、罗医生、顾文山，从左至右 | 透明半身立绘，按剧情的 `portrait` 字段切换 |
| `buildings.png` | 旧屋、印刷铺、诊所、档案室，2×2 排列 | 上海石库门街区建筑 |
| `props.png` | 书桌、床、书柜、印刷机、药柜、木箱、长椅、路灯、煤炉、自行车、窗帘、渡船 | 室内家具与街巷物件 |
| `terrain.png` | 石板、沥青、木地板、诊所瓷砖、砖墙、旧地毯，3×2 排列 | 地面与墙面连续纹理 |

角色的视觉识别：沈砚穿深蓝外套和旧围巾，周姨穿灰紫棉衣与围裙，林岚穿橄榄色工装并留长辫，罗医生穿旧白大褂与眼镜，顾文山留银发、戴圆眼镜、穿褐色开衫。地图上的行走精灵在 `src/characters.ts` 使用独立像素蒙版绘制，与立绘保持配色和服装特征一致。

## 绘制与替换

- `src/illustrations.ts` 保存裁切坐标。替换图集时同时调整对应的 `Frame`；透明图像应保留 Alpha 通道。
- 地图使用 32px 网格，行走精灵为 32×48，地形纹理缓存在 128×128 的画布中，对话立绘绘制到 192×320 的画布。所有缩放关闭图像平滑。
- 场景物件以碰撞矩形的底部为基准向上绘制，缓存后与角色按 Y 坐标排序。改变视觉大小时不要把底部移出碰撞范围。
- 立绘在桌面上从对话框左侧向上延伸；窄屏上与文字并排，保持 3:5 的宽高比。
- 网页构建单独缓存 PNG。`scripts/build-standalone.mjs` 把构建后的图片嵌入 `play.html`，因此直接打开单文件也能显示全部美术。
- 图片解码完成后，场景缓存会统一重建。加载期间仍可使用程序化绘制，不阻塞剧情与输入。

修改美术后执行 `npm run build` 和 `npm run test:e2e`，并检查 `docs/preview.png` 与室内截图。浏览器测试会核对五位角色的透明立绘、双语切换和手机比例，以及离线图片加载。
