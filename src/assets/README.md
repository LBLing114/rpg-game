# 雾渡美术资源

现有建筑、家具与人物图集由此前的生成式美术工具制作，角色设计与场景设定来自《雾渡》，不是 RPG Maker 编辑器自带的 RTP 素材。本轮地形、室内墙面和小物件改为 `src/scenery.ts` 中明确编写的像素绘制规则；保留原有建筑和立绘，未重新生成图片。运行游戏时无需生成服务或 API 密钥。

| 图集 | 内容 | 游戏中的用途 |
| --- | --- | --- |
| `portraits.png` | 沈砚、周姨、林岚、罗医生、顾文山，从左至右 | 透明半身立绘，按剧情的 `portrait` 字段切换 |
| `buildings.png` | 旧屋、印刷铺、诊所、档案室，2×2 排列 | 上海石库门街区建筑 |
| `props.png` | 书桌、床、书柜、印刷机、药柜、木箱、长椅、路灯、煤炉、自行车、窗帘、渡船 | 室内家具与街巷物件 |
| `terrain.png` | 旧版六类纹理图集 | 仅保留作历史资源；不再导入或打包到游戏 |

角色的视觉识别：沈砚穿深蓝外套和旧围巾，周姨穿灰紫棉衣与围裙，林岚穿橄榄色工装并留长辫，罗医生穿旧白大褂与眼镜，顾文山留银发、戴圆眼镜、穿褐色开衫。地图上的行走精灵在 `src/characters.ts` 使用独立像素蒙版绘制，与立绘保持配色和服装特征一致。

## 像素风格规范

- 地面以青灰、旧木褐、灰绿为主，暖黄只用于灯与窗。磨损使用相连的短线与色块，不铺满高对比噪点；保留大块安静的地面，让人物和交互物件容易辨认。
- `scenery.ts` 绘制石板、沥青、木地板、瓷砖、砖墙、水面，以及墙裙、窗台、电线、布帘、室内立灯、抽屉柜、航班告示和候船室柜台。颜色和尺寸在代码中直接编辑。
- 旧屋使用木质墙裙与窗帘，诊所使用灰绿墙面，货栈使用更暗的墙面与装卸标线；后弄加入晾衣夹、衣物缝线、搪瓷盆与排水沟。所有新增装饰都不改变碰撞、剧情触发或存档坐标。
- 长书架按完整书柜分段绘制，铅字桌与问讯柜台分别绘制，不把普通书桌拉长。房屋和家具脚底仅保留窄接触阴影，窗光与灯光局部使用。
- 所有程序化纹理使用固定坐标散列；不会每帧重新随机。背景和物件生成一次后缓存，角色与物件仍按脚底 Y 坐标排序。
- 对话窗口使用灰绿深色底、米白双线边框和扁平选项，维持原有手机布局与人物立绘比例。界面字形保留浏览器文字渲染，优先保证中英文可读性。

## 绘制与替换

- `src/illustrations.ts` 保存裁切坐标。替换图集时同时调整对应的 `Frame`；透明图像应保留 Alpha 通道。
- 地图使用 32px 网格，行走精灵为 32×48，地形由小色阶与稀疏磨损笔触绘制，缓存为整张地图背景，对话立绘绘制到 192×320 的画布。所有缩放关闭图像平滑。
- 场景物件以碰撞矩形的底部为基准向上绘制，缓存后与角色按 Y 坐标排序。改变视觉大小时不要把底部移出碰撞范围。
- 立绘在桌面上从对话框左侧向上延伸；窄屏上与文字并排，保持 3:5 的宽高比。
- 网页构建单独缓存 PNG。`scripts/build-standalone.mjs` 把构建后的图片嵌入 `play.html`，因此直接打开单文件也能显示全部美术。
- 图片解码完成后，场景缓存会统一重建。加载期间仍可使用程序化绘制，不阻塞剧情与输入。

修改美术后执行 `npm run build` 和 `npm run test:e2e`，并检查 `docs/preview.png` 与室内截图。浏览器测试会核对五位角色的透明立绘、双语切换和手机比例，以及离线图片加载。
