# 扩展序章流程（含剧透）

目标：首次正常阅读与地图探索约 25–35 分钟。以内容量估算，尚不是真人试玩计时结论。不要用自动点击测试的耗时作为游玩时长。

主线最直接阅读路线包含 54 个对话节点，约 6,780 个中文汉字或 4,038 个英文词；完成三个角色支线约 66 个节点、8,159 个中文汉字或 4,822 个英文词。全模组共 77 个节点，另含结局正文、道具说明、手记与任务文本。玩家可立即显示全文、切换语言、存档或回访。

| 段落 | 玩家行动 | 新增内容与进展 |
| --- | --- | --- |
| 开场 | 连续阅读六段背景 | 1968 年上海；1957 年归国；遭受政治迫害；1967 年弟弟失踪；一封旧信为何在今晚送达；今夜的具体目标 |
| 归家 | 和周姨交谈，进入旧屋调查书桌 | 区分邻里传言和亲眼所见；送纸回执日期、未寄短笺、合影；`homeClue` |
| 印刷铺 | 调查铅字盒，再和林岚交谈 | 压印顺序与铅条缺口；林岚的参与和迟疑；`typeClue` |
| 校样推理 | 选择证据确实支持的结论 | 正确：姓名在声称的定稿日期后被补印。错误：推断全部责任人、推断弟弟现状。可解释后重试；获得校样 |
| 诊所 | 读药柜旁值夜登记，再听罗医生证言 | 分开记录的时间与证人的记忆，保护患者信息；`medicalClue`、证言、船票；档案室开放 |
| 顾先生支线 | 使用合影或在对话中出示照片 | 青芜、桥与回忆；听完后获得 `remembered`，与保护医生的承诺共同影响“余灯” |
| 档案室 | 查靠墙书架索引，再查桌上名册 | 四十七号及附一；不同日期、同音姓名与空白签收的区别；`archiveClue` |
| 去向推理 | 判断转出记录的证据边界 | 正确：已转出，但不能确认抵达或现状；错误推理可重试。抄录后获得名册，原件留存；江岸开放 |
| 分存支线 | 带齐三份材料回访林岚 | 保护证人与患者、保留来源与未知；完成 `sharedPlan` 才开放“留名” |
| 告别支线 | 带名册回访周姨 | 如实回报已确认与尚未确认的消息；`farewellAunt`，完成“门边的灯” |
| 江岸 | 四段回顾后作最终选择 | 区分旧信错过的清晨和今天的船票；理解各条路的代价；可返回补线索再决定 |

结局：留名需要三份材料、信任与分存约定；余灯需要保护医生、顾先生回忆与名册；渡雾需要船票与名册；无声在江岸可选。结局后仍可回到最后选择。

数据仍位于 `src/data/storyData.json`，新增任务由声明式条件驱动。存档的状态版本仍为 1；封装新增 `contentVersion: 2`，旧存档只迁移已经获得道具对应的调查进展，当前版本读档不会凭空解锁分存结局。
