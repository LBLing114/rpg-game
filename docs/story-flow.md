## 公共调查与地图

原有六图保留，新增三张 32px 城市地图。无草地。地图物件与行走图继续按脚底排序，碰撞和寻路共享同一份网格数据。

- 槐生里西口 ↔ 槐生后弄：退信箱、公用水槽、晾衣绳、煤炉、寄存长凳。
- 后弄 ↔ 沿江货栈：明确的装卸通道、货位标线、点交桌、封存台、待运木箱。
- 货栈 ↔ 夜航候船室 ↔ 黄浦江岸：长凳、旧航班表、问讯窗口、侧门。
- 新增旧屋皮箱、诊所病床、档案室更正表交互；原有地图门口出入位置保持一致。
- 取得名册开放后弄；完成退信核对开放货栈；完成货单核对开放候船室。地图快捷旅行遵守相同锁定条件。
- 金色场景标记、地图标记、任务中的地点指引指向当前调查或路线任务。

公共流程：六段黑幕序幕 → 周姨与旧屋 → 印刷校样推理 → 诊所登记与证言 → 档案索引与转运推理 → 后弄退信 → 货栈货单 → 候船室旧表 → 江岸分线。

后弄选择私下核对或公开邀请邻居，会分别进入两段新剧情，随后在留证寄存任务中触发不同反馈。货栈选择遮名节录或完整受限抄本，各有两段独立处理过程。两种版本都须尊重已有查阅约定。

## 四条独立路线

| 路线 | 进入条件 | 三段实地任务 | 影响结局的关键选择 | 结局 |
| --- | --- | --- | --- | --- |
| 留证 | 三份材料、信任、回访林岚完成分存准备 | 货栈封存台 → 后弄寄存长凳 → 印刷铺铅字盒 | 封存时是否署名；寄存时回应早先的公开/私下核对 | 留名 / 无名存证 |
| 护人 | 名册、保护医生、顾先生的合影回忆 | 诊所帘后病床 → 后弄煤炉 → 候船室靠窗长凳 | 是否邀请轮值；只承诺三夜不获得互助网 | 余灯 / 接灯 |
| 离沪 | 名册、渡票 | 旧屋皮箱 → 货栈待运箱 → 候船室靠窗长凳 | 是否带地址簿核对远行条件；不能临时凭空获得接应 | 渡雾 / 归巷 |
| 缄默 | 名册 | 档案室更正表 → 旧屋皮箱 → 候船室靠窗长凳 | 是否保留自己的草稿；不销毁他人的原件 | 无声 / 未寄 |

每条路线在江岸选定后记录唯一的路线标记。每一步完成前，不能跳到下一步或直接触发结局。全部三步完成后，到候船室问讯窗口选择最终行动；其后还有三段独立后果，最后才出现结局卡。

署名是“留名”的必要条件；邀请轮值是“接灯”的必要条件；核对地址是“渡雾”的必要条件；保留草稿是“未寄”的必要条件。拒绝这些承诺仍可通关到对应的另一种结局。已经准备充分的玩家仍可在最后选择更谨慎的收束。

## 存档与重玩

保存仍使用原有版本和存储键，自动档与三个手动档不被迁移清空。新旧存档都只保留实际取得的旗标，不因载入获得新增路线进展。旧江岸进度先补三处公共调查；旧结局返回后也可继续补玩。

在江岸分线前保存手动档。结束后“回到本路线的最后选择”只重看本路线可用的收束，不能绕过早先的署名、轮值、地址或草稿决定。体验另一条完整后半程需要读取分线前存档。结局收集独立保留，共八项。

## 数据与回归验证

正文、嵌套地点选择器、路线元数据、条件与任务全部位于 `src/data/storyData.json`。`routes` 定义步骤的地图、事件与完成旗标，任务 `when` 让另一条路线的目标不混入当前手记。共 205 个双语对话节点，28 项任务定义（单路线显示 19 项，含 3 项可选）。

`npm test` 检查全部八结局、三图顺序解锁、门口互返、路线互斥、早期选择后果、读档恢复和全部可走网格连通；`npm run test:e2e` 实际点击完整公共流程与四路线八结局，并验证单文件离线运行、手机排版和匿名选择的读档限制。
